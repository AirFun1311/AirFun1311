## Executive Profile & Engineering Philosophy

Systems architect specializing in **automated compliance verification, software supply chain integrity, and privacy-enhancing technologies**. Engineering focus bridges complex global regulatory doctrines and low-latency, automated software systems.

* **Zero Trust & Fail-Closed Design**: Security and compliance must be evaluated programmatically at build time, runtime, and network egress.
* **Global Jurisdictional Modeling**: Continuous analysis across **EU GDPR / NIS2**, **US NIST CSF 2.0 / CCPA**, **China PIPL**, and **Israel PPL Amendment 14**.
* **Software Supply Chain Integrity**: Full implementation of OpenSSF and GitHub Security standards (Automated SBOM generation, CodeQL SAST, Dependabot SLAs, and SLSA Level 3 provenance).
